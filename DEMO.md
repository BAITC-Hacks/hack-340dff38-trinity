# Демонстрация Qadam — до 5 минут

Перед защитой запустите приложение и откройте вторую вкладку с этой инструкцией. Все действия ниже выполняются в приложении. Не обновляйте страницу специально для сброса: данные сохраняются. Для чистой репетиции используйте отдельный профиль браузера.

## 0:00–0:25 — проблема

Покажите каталог: все задачи доступны, рейтинги 100, 90, 82, 50, 35. Скажите: «Основная геймификация направлена на бизнес: чем яснее задача, тем выше её позиция. Команды выбирают сами».

Профиль сверху: «Бизнес · Ателье Forma». Нажмите «Создать задачу» → «Взять пример ателье» → «Получить уточняющие вопросы». Назовите ограничение: «AI здесь представлен разрешённой локальной заглушкой; внешний API не подключён».

## 0:25–1:10 — слабая карточка и подтверждение

Покажите минимум три уточняющих вопроса. Для короткой демонстрации оставьте ответы пустыми и нажмите «Собрать карточку».

Название: «Быстрый учёт заказов ателье».

Исходный текст уже заполнил контекст и потребность, остальные сведения неизвестны: предварительный рейтинг 20. Подтвердите флажком и опубликуйте. Задача появится в каталоге внизу, но отклик доступен.

## 1:10–2:20 — улучшение и рост позиции

Нажмите «Редактировать». Заполните:

| Поле | Текст |
|---|---|
| Пользователи | Администратор и мастера ателье |
| Сценарий | Администратор создаёт заказ, мастер меняет его статус |
| Данные | Обезличенная таблица 120 заказов |
| Формат данных | CSV |
| Доступ | Передадим выбранной команде на первой встрече |
| Ожидаемый результат | Прототип учёта заказов с поиском и статусами |
| Формат передачи | Работающий сайт и исходный код |
| Критерии | Все 120 заказов импортируются без потерь |
| Приёмка | Администратор проверит на 10 тестовых заказах |
| Ограничения | Без платных сервисов и персональных данных |
| Срок проекта | 3 недели после выбора команды |
| Контакт | project@forma.example |
| Консультации | Онлайн по вторникам |
| Обратная связь | Алия отвечает в течение 2 рабочих дней |

Покажите предварительный рейтинг 100, подтвердите. После сохранения сообщение покажет +80 и смену позиции. В каталоге задача стала приоритетной. Не заполняйте условия наград и дедлайн, если нужно уложиться в пять минут: они необязательны.

## 2:20–3:10 — предложение

Переключитесь на «Команда · Byte Collective». Откройте новую задачу, заполните:

- Идея: «Сделаем единый список заказов с карточкой, сроками и статусами».
- План: «Проверим процесс, соберём прототип, проведём приёмку на тестовых заказах».
- Срок: «3 недели».
- Ссылка: `./prototype.html` (локальный общий пример, разрешённый специально для демо).

Отправьте. Скажите: «Рейтинг готовности не ограничивает право команды подать предложение. За отправку выдаётся значок, но не баллы подтверждённого прогресса».

## 3:10–3:50 — ручной выбор

Вернитесь в бизнес-профиль и откройте «Предложения». Найдите новую задачу: виден псевдоним команды, а не её имя или достижения. Нажмите «Выбрать команду» и подтвердите. Откроется название Byte Collective.

Покажите две исходные заявки на первую задачу Forma: их можно выбрать обе либо отклонить обе. Выбор первой не меняет остальные.

## 3:50–4:40 — подтверждённый результат

Переключитесь на Byte Collective → «Мои предложения». В выбранном предложении заполните этап:

- Что сделано: «Готов прототип учёта; создание и изменение статуса заказа работают».
- Ссылка: `./prototype.html`.

Отправьте на подтверждение. Переключитесь на бизнес → «Предложения» → «Подтвердить этап». Подтвердите в диалоге.

Вернитесь на команду → «Мой прогресс»: 50 баллов, статус «Практик», значок «Первый результат». Повторного начисления нет.

## 4:40–5:00 — границы и развитие

«Работают общий и приватный текстовый чат, дедлайны, награды как условия и достижения. Данные сохраняются в этом браузере. Настоящую регистрацию, серверную защиту, реальный AI API и сезонный топ-5 оставили на следующий этап».

Если спросят об ошибках AI, откройте новый конструктор и выберите «Некорректный ответ» в резервном сценарии: текст сохранится и появятся резервные вопросы.
